# 14-Day Self-Discovery & Reclamation Journal

A gentle, trauma-informed 14-day guided journal designed to help individuals deconstruct high-control dynamics, heal from guilt, and reclaim personal autonomy.

## 🌟 Project Overview
- **Format**: Notion Template & Glide Web App Architecture
- **Target Audience**: Individuals recovering from high-control environments, spiritual trauma, or intense guilt.
- **Language**: English

## 📂 Repository Structure
- `prompts/`: Daily self-discovery reflection prompts (Day 1 - Day 14).
- `database/`: Schema setup for Google Sheets / Glide integration.
- `docs/`: Product descriptions and setup guides.

## 🚀 How to Use
1. **Notion Version**: Import the 14-day journal template into your Notion workspace.
2. **App Version**: Connect the Google Sheets database to Glide Apps to use the mobile web app format.
